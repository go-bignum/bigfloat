# bigfloat

Correctly rounded elementary functions and constants on Go's `math/big.Float`,
at any precision and in all six rounding modes. Pure Go, no cgo, no
dependencies.

```go
import "github.com/go-bignum/bigfloat"

z := new(big.Float).SetPrec(113).SetMode(big.ToNearestEven)
bigfloat.Exp(z, x)    // e^x, correctly rounded to 113 bits
z.Acc()               // big.Below / big.Exact / big.Above: the side of the exact value
```

## What is provided

| | |
|---|---|
| roots | `Sqrt`, `Cbrt`, `Root(z, x, n)`, `Hypot` |
| exponentials and logarithms | `Exp`, `Expm1`, `Log`, `Log1p`, `Log2`, `Log10`, `Pow` |
| trigonometric | `Sin`, `Cos`, `Tan`, `Asin`, `Acos`, `Atan`, `Atan2` |
| hyperbolic | `Sinh`, `Cosh`, `Tanh`, `Asinh`, `Acosh`, `Atanh` |
| constants | `Pi`, `E`, `Ln2`, `Ln10`, `EulerGamma` |
| oracle harness | package `oracle`: mpmath driven from Go, correctly rounded reference values, golden fixtures; `oracle.Self` uses this package as the reference |

## The guarantee

Each function returns the **exact result rounded** to the receiver's
precision in the receiver's rounding mode (`ToNearestEven`, `ToNearestAway`,
`ToZero`, `AwayFromZero`, `ToNegativeInf`, `ToPositiveInf`) — the MPFR
contract — and `z.Acc()` tells on which side of the exact value it lies. So
results are reproducible bit for bit on every architecture and every Go
version.

Conventions are `math/big`'s: a receiver of precision 0 takes the operand's
precision (64 bits for constants); the receiver may alias an operand;
overflow gives ±Inf and underflow ±0 exactly as `big.Float`'s arithmetic
does; special values follow C99 Annex F (`Atan2(±0, -0) = ±π`,
`Pow(-1, ±Inf) = 1`, …). An operation whose result would be NaN panics with
`bigfloat.ErrNaN`, as `big.Float.Sqrt` panics with `big.ErrNaN`. Note that
`big.Float.Sqrt` itself is not correctly rounded in every mode;
`bigfloat.Sqrt` is.

How: every approximation is a rigorous enclosure (midpoint-radius balls,
fixed-point series with bounded error), evaluated by Ziv's strategy — raise
the working precision until the enclosure rounds to a single value — with
exact results (exp(0), log2(2^k), perfect powers, 4^1.5, …) and
near-identity results (sin x for tiny x, tanh of large x) settled before the
loop. Argument reduction is exact for any argument (`Sin(1e300)` at 53 bits
is right). [docs/design.md](docs/design.md) gives the algorithms and their
references (Brent & Zimmermann's *Modern Computer Arithmetic*, MPFR, Ziv,
Arb, Chudnovsky, Brent–McMillan).

## How it is verified

- **Golden fixtures from mpmath 1.4.1**, generated by `go run ./cmd/oracle`
  (Go draws the arguments, drives mpmath over a pipe at a precision well
  above the target, and certifies each rounding): 28 850 cases over the 29
  functions and constants — tiny arguments, the bulk of each domain, huge
  arguments, the neighbourhood of singularities and of multiples of π/2,
  exact cases, and arguments longer than the result — at 24, 53, 64, 113, 200
  and 1000 bits (constants at every precision from 2 to 300 and at 500, 1000,
  2000). Each case is checked in all six modes, value, sign of zero and
  accuracy: **173 100 results, all identical** to the certified roundings.
- **Fuzzing** (`FuzzFunctions`): every function, mode and precision against
  the oracle `Rounder` at more than twice the precision; only `ErrNaN` and
  `ErrLimit` may panic.
- Special values and domain errors by table, unit tests of the error model,
  100% statement coverage with `-race`, and the fixtures on amd64, arm64,
  386, arm, riscv64, loong64, ppc64le and s390x in CI.

## Resource bounds

Arguments may come from untrusted input: no input makes a function run
unbounded. Trigonometric arguments are limited to an exponent of
`MaxReductionExponent` (2^22; beyond it `Sin`, `Cos`, `Tan` panic with
`bigfloat.ErrLimit`), the Ziv loop to 64·(p + argument precision) + 65536
bits, exact integer roots and powers to 2^20 bits of work; other costs grow
with the requested precision and the arguments' own size. Details in
[docs/design.md](docs/design.md#resource-bounds).

## The oracle, for other packages

```go
m, _ := oracle.StartMpmath(nil) // uv run --with mpmath==1.4.1 …
defer m.Close()
r := &oracle.Rounder{Oracle: m} // or oracle.Self{}: no Python needed
res, _ := r.Round("atan2", 53, y, x) // one correctly rounded result per mode
```

`oracle.Fixture` / `Case` store and check results; see
[docs/design.md](docs/design.md#the-oracle-for-the-fleet).
