# Performance against mpmath

`go run ./cmd/bench -rounds 5 -out docs/perf.md` (this preface is added by
hand): bigfloat with GOMAXPROCS=1 against mpmath 1.4.1 (pure-Python backend,
timed inside its own process) at the same precision, rounds interleaved,
best of each side. Apple M4 Max, Go 1.27.1, 2026-10-21, one-minute load
average between 6.5 and 8 during the run (other sessions on the machine).
bigfloat returns correctly rounded results with a certified `Acc()`; mpmath
returns results within its working precision.
